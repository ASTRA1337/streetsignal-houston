# StreetSignal Houston

An open-source civic technology project focused on
street-safety evidence and intervention intelligence
in Houston, Texas.

## Mission

Connect fragmented public crash, 311 infrastructure,
roadway, and transportation project records around
physical locations.

Help residents, researchers, journalists, and civic
organizations build source-linked Street Safety Cases.

## Initial Scope (v0.1)

- Houston traffic safety
- Relevant 311 infrastructure reports
- Roadway and geographic context
- Publicly documented safety interventions
- Evidence timelines and source traceability

## Initial Case Study

Bissonnet Street & Wilcrest Drive
Houston, Texas

## Development Stack

- Python 3.14
- VS Code
- Git / GitHub
- DuckDB / Parquet (planned)
- GeoPandas / Shapely (planned)
- pytest (planned)

## Project Status

Early development: environment setup and initial

## Development Principles

- Evidence-first analysis
- Reproducible and transparent methodology
- No unsupported causal claims
- Free and open-source tooling
- Start with one validated Street Safety Case
